# X-Prompter - Search and choose prompts from a list.

## Core functionality

- Create a md:markdown reader with search functionalities and more in future from Prompts.md.
- Search and choose prompts from a categorized Prompts.md file.
- Edit prompt like form/dialog.
- Display the prompt
- Copy the selected prompt

## Additional features

- Saving with star emojis favorite prompts
- Save the output to a file
- Save the output and prompt to a file
- Save the prompt to a file
